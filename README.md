WHAT I MADE

This is an AI-generated pizza simulator game made in Godot. 


HOW TO RUN IT

Download Godot from these respective links depending on your operating system.

WINDOWS

https://godotengine.org/download/windows/


MAC

https://godotengine.org/download/macos/



Uncompress the installed Godot from its ZIP then run it


Then download my game from this very branch as a ZIP

Unzip it and then go into Godot and open the folder "pizza-simulator" in Godot. Then click run to play the game



WHAT I SET OUT TO DO

I wanted to build a game in Godot, a game engine I was not familiar in, with the use of an AI agent. I wanted to tackle aesthetic, gameplay, and directing AI challenges and I did just that.



WHAT I LEARNED

I learned how important commit history is and the benefits of creating 3D models for the AI to utilize. It was more helpful for me to model and rig a character than for AI to do it as well as modeling a more complex object like the oven. So the AI could handle the more complex task of animating the characters and other assets



WHAT DOESN'T WORK YET

The animation for the pizza minigames is primtive, the characters are basic and there is no reward system/cash earned for finishing the pizzas. I also wish I had more than one customer and that there were different reactions to the pizza quality animation-wise.


WHAT I'D DO NEXT

I would have a clearer blueprint of gameplay goals, desired assets, and rescoping set out from the beginning. My original draft had a framework but not enough specificity for the working process. I will implement such fixes in my upcoming work.
