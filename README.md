NORA WENTZ - HSG-5232-A: PRGM ANIMATORS

    This is a Python script generated by Artificial Intelligence meant to run in Maya which, when deployed makes a series of random shapes with random colors and it features a simple GUI where the user can change the height, depth, width and minimum spacing of the shapes. 

    It can be run from dropping it into Maya or by copying and pasting the command into Python script editor. 

    I wish I had added a setting where the user could change the saturation of the shapes so each could have their own intensities
