# Pizza Simulator - Quick Start

## 🚀 Get Started (3 Steps)

### 1. Open Godot 4.7
```bash
# Import project folder
# File → Import → Select pizza-simulator directory
```

### 2. Run the Game
```bash
# Press F5 or click Play
# First run may take a moment to compile
```

### 3. Play!
Follow the HUD instructions to make pizzas!

## ⌨️ Controls
```
W/A/S/D  - Move
SHIFT    - Sprint
SPACE    - Jump
MOUSE    - Look
E/L-CLICK - Interact
ESC      - Toggle Mouse
```

## 🎯 Basic Order
1. Press E at **DOUGH_STATION** (left)
2. Move to **PREP_TABLE** (center)
3. Press E on dough
4. Go to **SAUCE → CHEESE → TOPPINGS** (left)
5. Return to **PREP_TABLE** and click dough
6. Go to **OVEN** (top), press E
7. Wait for "done", then **COUNTER** (right), press E

## 📊 Your First Pizza
**Order:** Pepperoni
**Time:** 60 seconds
**Goal:** 100 points (perfect bake + toppings match)

**Points:** toppings 40% + bake 40% + speed 20%

## 🎨 Visual Guide
- **Cream box** = Dough station
- **Red box** = Sauce station
- **Yellow box** = Cheese station
- **Dark red box** = Toppings station
- **Grey box** = Prep table
- **Dark box** = Oven
- **Black box** = Counter

## 🏆 Score Tips
1. **Speed matters** (20% of score)
2. **Perfect timing** (40% of score)
3. **Correct toppings** (40% of score)

## 📱 HUD Elements
```
[ORDER: Pepperoni, Mushroom]        ← What you need
[Score: 0     Pizzas: 0]            ← Your stats
[Order time left: 60 s]             ← Timer (with bar)
[Hands: empty]                       ← What you're holding
[Hint: Press E on dough]            ← What to do
```
